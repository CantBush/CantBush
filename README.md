A cited RAG assistant for Limbus Company lore. Ingests wiki pages, retrieves with BM25, dense vectors, and graph neighbors, then answers through a LangGraph grade-and-refine loop served by FastAPI.

### [Multi-agent reinforcement learning cellular automata](https://github.com/Petroleum-Blownapart/nn_game_of_life)

A cellular automata simulation in PyTorch where each cell runs its own neural network to model surrounding-cell behavior. Managed and visualized 2,500 neural networks, producing an animation and a research paper documenting the simulation and future research directions.

### [Transfer learning image classification](https://github.com/CantBush/144FinalProject)

Image classification for 100 classes using EfficientNetV2-Small and Swin-Base with transfer learning. MixUp, test-time augmentation, layer-wise learning rates, stochastic depth, and hyperparameter tuning reached 83% classification accuracy.

### [Facial recognition attendance](https://github.com/CantBush/FacialRecognition)

An attendance system that marks presence from facial data using OpenCV and face-recognition libraries — built for classrooms and workplaces that need faster, more reliable check-in.

### [Credit card fraud detection](https://github.com/CantBush/CreditCardFraudDetection)

Analyzed 100,000+ transactions in R. SMOTE and sampling balanced a highly skewed dataset; CART trees were evaluated with precision, recall, and confusion matrices.

### Huffman encoding

File compression and decompression implemented from scratch in Python — a greedy encoding of character frequencies into a prefix-free tree.
